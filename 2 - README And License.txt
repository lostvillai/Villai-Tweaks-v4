## 🔥 The Most Advanced Gaming Optimizer for Windows

LOSTVILLAI Tweaks V4 is a powerful batch script that optimizes your Windows PC for **maximum gaming performance**. Reduce ping, boost FPS, eliminate input lag, and unlock your system's full potential.

## ⚡ Features

### 🌐 Network Optimization
- **DNS Auto-Test** - Automatically finds and configures fastest DNS
- **Network Boost** - TCP/IP optimization for lowest latency
- **Ping Reducer** - Advanced registry tweaks to minimize ping
- **WiFi/Ethernet Priority** - Set connection priority for gaming

### 💻 Performance Tweaks
- **Ultimate Power Plan** - Zero power-saving, maximum performance
- **CPU Optimizer** - Disable core parking, optimize scheduling
- **GPU Turbo** - Hardware-accelerated GPU scheduling
- **RAM Cleaner** - Memory management optimization

### 🎮 Gaming Enhancements
- **FPS Booster** - Disable Game Bar, fullscreen optimizations
- **Input Lag Fix** - Remove mouse acceleration, keyboard delays
- **Game Priority** - Set any game to high priority automatically
- **Fortnite Pack** - Fortnite-specific optimizations

### 🛠️ System Maintenance
- **Deep Cleaner** - Remove temp files, cache, prefetch
- **Bloatware Remover** - Disable telemetry and tracking
- **Service Optimizer** - Disable performance-killing services
- **Startup Manager** - Optimize boot time

### 🔧 Utilities
- **System Restore** - Create backup before tweaking
- **Revert Changes** - Easy rollback guide
- **System Info** - View hardware specs
- **Gaming Benchmark** - Test ping to game servers

### ⚙️ Quick Actions
- **SAFE MODE** - Apply all safe tweaks at once
- **EXTREME MODE** - Maximum performance (aggressive)
- **QUICK START** - Essential tweaks only

## 📥 Installation

1. **Download** `LOSTVILLAI_V4.bat`
2. **Right-click** → **Run as Administrator**
3. Choose your tweaks or use Quick Actions

## ⚠️ Requirements

- Windows 10 or Windows 11
- Administrator privileges
- **Create a restore point before using!**

## 🚀 Quick Start Guide

### First Time Users (Recommended)
1. Run script as Administrator
2. Press **[17]** to create restore point
3. Press **[A]** for SAFE MODE (all safe tweaks)
4. Restart your PC

### Advanced Users
1. Create restore point
2. Press **[E]** for EXTREME MODE
3. Restart your PC

### Specific Tweaks
- Low ping? Use options **[1-4]**
- Low FPS? Use options **[5-12]**
- System cleanup? Use options **[13-16]**
